## About The Project

This repository is the unmodified create-next-app scaffold for a Next.js 12 app, shipping only the default Pages Router welcome page and one example API route with no custom application code added on top.

`pages/index.js` still renders the generated welcome page with its links back to the Next.js docs, the Next.js Learn course and Vercel's own deploy flow, and `pages/api/hello.js` is the starter's own example API route, which always answers with `{ "name": "John Doe" }`. `package.json` pins `next` at 12.1.0 with React 17 and defines the four standard scripts (`dev`, `build`, `start`, `lint`); nothing beyond what `create-next-app` generates has been added.

See the [open issues](https://github.com/anyingiit/Stydy_vercel_nextjs/issues) for planned features and known issues.

## Getting Started

### Prerequisites

- A Node.js runtime able to run Next.js 12 (see the `next` dependency in [`package.json`](package.json))
- Yarn, since dependencies are pinned in [`yarn.lock`](yarn.lock) rather than `package-lock.json`

### Installation

```sh
git clone https://github.com/anyingiit/Stydy_vercel_nextjs.git
cd Stydy_vercel_nextjs
yarn install
```

## Usage

```sh
yarn dev
```

This starts the Next.js dev server on http://localhost:3000, serving the generated welcome page and, at `/api/hello`, the example API route's `{ "name": "John Doe" }` response.
